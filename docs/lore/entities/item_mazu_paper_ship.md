# 实体档案：妈祖的彩纸海船 (Colorful Paper Ship of Mazu)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：大英图书馆现存的福建海澄（月港）道教航海科仪手稿（OR12693/18）[7]。
* **L2（学术）**：南中国海船员在航经危险暗礁时，会制作带有微型风帆和船舵的彩纸小船，放入海中以安抚水鬼 [7]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 遭遇极端风暴时的消耗类高阶保命道具/仪式。
* **Q2 异**：✓ 深刻还原了东亚独有的航海宗教仪轨。
* **Q3 链**：✓ 链接明朝/东南亚船员、月港走私网、L4神秘学暗线。
* **分级**：必加（L4 神秘学暗线）。

## 3. 视角自查 (P1-P5)
* **亚洲视角**：船员在生死边缘与自然力量和解的严肃仪式，是闽南航海传统的精神支柱 [7]。
* **西方视角**：不理解此行为，视为“异教徒的迷信”，体现文化隔阂。

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“在大明和马六甲的航线上，如果你遇到狂风，记住在甲板上扎一艘五彩纸船扔进海里。别问为什么，海底的东西吃了饭，就会放你过去。”
* **记录 (Archives Record)**：“大明海商在远洋帆船上常设‘香公’（Incense Master）一职。途经危险海域时，他们会制作纸船放入海中进行科仪，祈求妈祖庇护并驱逐邪祟。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】西方船客把闽南水手扎彩纸船投海视作‘异教徒的迷信’，是只看见了纸船，没看见船上人此刻的处境。船过危礁、风浪正紧，人力已到尽头，水手便制一艘带帆带舵的小船放入海中——它替整船人向妈祖、向水中无主的孤魂递上一份谦卑：愿以这只小船代一船人受过，求一程平安。这不是要安抚什么深海的守护者，而是闽南航海传统里一套与不可控的大海讲和的方式：把无能为力的恐惧，收拢进一桩郑重、可执行的仪式，让濒临崩溃的船心重新安定下来。本会收录它，与普世遗产无关，只因它与地中海桅下的冥河银币、马来巫师的镇海真言遥相呼应——不同的海、不同的神，同一颗在风浪前学着低头的人心。”

> **博物层：已按 D7 去机器改写（2026-06-14）** — 删去「低频深海物质共振 / 远古海栖畸变体守护者」的机器变异设定，改为彩纸船科仪作为闽南航海传统中与大海讲和、安定船心的禳灾仪式，并与他文化同类仪式并置呼应。原机器版见 git 历史。
