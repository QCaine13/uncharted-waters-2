# 实体档案：巴芬岛的“愚人金”矿石 (Baffin Island "Fool's Gold" Ore)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：1578 年英国探险家马丁·弗罗比舍（Martin Frobisher）在寻找西北航道（Northwest Passage）时的航海日志与财务记录。
* **L2（学术）**：弗罗比舍在加拿大巴芬岛（Baffin Island）发现了大量他认为是金矿的黑色石头。在伊丽莎白一世和投资人的狂热支持下，他运回了超过 1000 吨这种矿石。最终冶炼证明，这只是毫无价值的角闪石和黄铁矿（Hornblende/Pyrite），这成为了英国早期探险史上最大的企业欺诈与灾难之一。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家在极北海域（如靠近北美东北部）探险时可能获取的特殊货物。起初被标记为“金矿石”，回港鉴定后价值暴跌为零。
* **Q2 异**：✓ 极具讽刺意味的“假财宝”事件，生动刻画了大航海时代晚期欧洲各国对美洲财富的狂热与盲目。
* **Q3 链**：✓ 链接北极探险线、伦敦投资公会、Otto 路线的英国扩张背景。
* **分级**：必加（L3 国家级企业泡沫与探险狂热）。

## 3. 视角自查 (P1-P5)
* **英国/欧洲视角**：为了追赶西班牙在南美的黄金霸权，英国人陷入了集体的财富臆想症，连女王都被毫无价值的石头蒙蔽了双眼。
* **美洲原住民视角**：那些苍白面孔的异乡人开着巨大的船来到冰天雪地，疯了一样地把我们用来垫帐篷的黑石头挖走，他们大概是被风雪冻坏了脑子。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Otto (见证英国皇家投资的巨大泡沫) / Ernst (记录极地的荒谬发现)
* `darkLineLayer`: L3（资本狂热与地理探险的致命结合）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“伦敦港的股票交易所彻底疯了！那个叫弗罗比舍的船长在冰天雪地的西北方挖到了一座金山！女王陛下亲自投资了他的船队。快去买他公司的股份吧，听说他们拉回来的黑色矿石，里面全都是纯金！”
* **记录 (Archives Record)**：“1578 年由马丁·弗罗比舍从巴芬岛（Baffin Island）运回英国的矿石标本。这些曾引发全英国狂热投资、被误认为高纯度金矿的石头，最终被皇家冶炼厂证实为毫无价值的角闪石与黄铁矿。它标志着英国早期向美洲扩张时遭遇的一次惨痛金融与探险教训。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】关于弗罗比舍那一千吨黑石头，本会的结论与皇家冶炼厂别无二致：那确确实实只是毫无价值的角闪石与黄铁矿——后者金灿灿、压手沉，恰是水手口中‘愚人金’（Fool’s Gold），千百年来骗倒过无数贪心的眼睛。这桩闹剧里没有任何阴谋，也没有谁在暗中诱导：是伊丽莎白一世的英格兰急于追赶西班牙在新大陆的金银霸业，整个伦敦陷入了集体的财富臆想，连女王都拿真金白银押注一座并不存在的金山。它是早期股份制探险最惨痛的一记教训。本会之所以把这堆废石郑重存档，正因为它是一面镜子：当一群人被‘那里有无尽财宝’的念头点燃，便会把矿渣看成黄金、把冻土看成宝库。本会内部，极端派同样为追索遗产而近乎癫狂——巴芬岛的教训，本会自己也当引以为戒：贪欲面前，最先被蒙蔽的，往往是最聪明的人。”
