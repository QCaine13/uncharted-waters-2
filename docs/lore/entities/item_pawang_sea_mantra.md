# 实体档案：帕旺的镇海真言 (Pawang's Sea Mantra)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：马来半岛及刁曼岛（Pulau Tioman）地区流传的土著巫师（Pawang）口述传统与驱魔祷文 [8]。
* **L2（学术）**：在前殖民时期，马来水手在出海时会依赖 Pawang 念诵特殊的真言（Mantera），召唤名为 Raja Bus 和 Raja Bas 的海洋灵体，以确保船只在恶劣海况或遭遇鳄鱼/海怪时免遭倾覆 [8]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 东南亚港口可雇佣特殊 NPC 或购买的消耗型航海增益道具（免疫一次触礁或海怪攻击）。
* **Q2 异**：✓ 完美展现了东南亚地区融合了伊斯兰、印度教与泛灵论的独特航海法术系统 [9]。
* **Q3 链**：✓ 链接马六甲/北大年港口、东南亚本地水手信仰、Ernst 的民俗记录。
* **分级**：必加（L4 航海神秘学）。

## 3. 视角自查 (P1-P5)
* **东南亚视角**：这是与海洋残酷力量达成契约的生存智慧，是祖先流传下来的实用航海技术。
* **欧洲视角**：完全无法理解的异教巫术，但老练的欧洲船长会为了保命而暗中默许船上的马来水手使用它。

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“如果在彭亨州（Pahang）的沿海遇到暗礁，赶紧找船上的马来水手念诵那段献给海洋统治者‘Sultan Gila’的咒语 [8]。哪怕船底已经被撕裂，那些看不见的东西也会托着你的船底撑到靠岸。”
* **记录 (Archives Record)**：“马来半岛的传统航海真言（Mantera）。水手们相信，通过巫师（Pawang）向海魔 Raja Bus 和 Raja Bas [8] 祈求，能够获得‘向左七寻、向右七寻’的无形结界，延长船只在海难中的浮力。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】欧洲船长私下默许马来水手念诵 Pawang 的镇海真言，又当众斥之为异教巫术，这份口是心非里藏着实情：这套真言确实‘管用’，只是不靠任何海兽或机括。它真正的力量在人不在海——惊涛骇浪、暗礁迫近之际，几十名水手依着 Pawang 的领诵同声祷念那段古老的韵文，散乱的呼吸与桨橹便被收束进一个节拍，恐慌让位于齐心，操船的手于是稳了下来。‘向左七寻、向右七寻的无形结界’，结的不是海上的界，是一船人的胆气。这套融合了伊斯兰、印度教与本土泛灵论的航海祷文，是东南亚水手与残酷海况达成的生存契约。本会记录它，不为它能搅动什么深海，而因它与闽南的彩纸船、地中海的桅下银币如出一辙——人在大海面前，总要为自己挣一桩可执行的安心。”
