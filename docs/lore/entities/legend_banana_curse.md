# 实体档案：航海禁忌：厄运芭蕉 (The Banana Curse)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：欧美帆船时代广为流传的“十大航海迷信”（Nautical Superstitions）之一 [6, 7, 10]。
* **L2（学术）**：自大航海时代起，西方水手极度恐惧将香蕉（Bananas）带上船。他们认为香蕉会带来厄运、引发风暴，甚至导致全船人神秘死亡。一旦在船上发现香蕉，船长通常会命令将其立刻扔进海里 [6, 7]。

> 注（来自转录原文）：关于香蕉释放乙烯气体与藏匿毒蜘蛛的具体生物学细节属于为丰满设定引入的外部延伸知识，需独立核实。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家在加勒比/西非港口采购补给时，若携带特定水果类货物出航，可能触发的船员士气暴跌或哗变事件。
* **Q2 异**：✓ 这是最著名的荒诞航海迷信之一，生动展现了底层水手的恐慌。
* **Q3 链**：✓ 链接加勒比航线、船员士气管理机制、西方水手 NPC。
* **分级**：必加（L4 神秘学与生物学投射）。

## 3. 视角自查 (P1-P5)
* **水手视角**：香蕉是魔鬼的果实，装载它的船只经常会毫无征兆地漂在海上变成鬼船，这是无数人命换来的教训。
* **信标会视角**：对基础生物学无知导致的幸存者偏差。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Catalina (处理船员的迷信恐慌) / Ernst (记录新大陆作物的特性)
* `darkLineLayer`: L4（航海迷信的生物学解构）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“把那串黄色的恶魔果实给我扔下船！你疯了吗？！你没听说过上个月从几内亚回来的那艘船吗？全船人都死光了，只剩下一底舱烂掉的香蕉！这东西会招来海神的诅咒！”
* **记录 (Archives Record)**：“帆船时代最诡异也最严格的迷信之一：严禁将香蕉带上远洋商船。水手们坚信香蕉会带来厄运，因为历史上有太多装载香蕉的船只遭遇了食物腐败、火灾或船员离奇暴毙的惨剧。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派生物档案】水手口中的‘诅咒’实为基础的生化反应。香蕉在成熟过程中会释放大量的乙烯气体（Ethylene gas），在通风极差的木制帆船底舱中，乙烯会加速周围所有其他补给的腐烂，导致致命的败血症爆发。此外，香蕉串是剧毒的热带游走蛛（Wandering Spider）最爱的栖息地，夜间爬出的毒蜘蛛才是那些离奇暴毙的真凶。迷信，只是无知者对自然法则的战栗。”

> **博物层分类：[留]** — 纯生物学解释（乙烯加速腐烂、毒蜘蛛），无机器，无普世遗产引用。
