# 实体档案：圣克鲁斯异色青花瓷 (Santa Cruz Atypical Blue-and-White)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：菲律宾海域发掘的 15 世纪中叶（大明海禁时期）Santa Cruz 沉船水下考古报告 [1]。
* **L2（学术）**：该沉船出水的明代中叶青花瓷中，存在大量釉面缺陷（glaze defects）和非典型的色彩变异（atypical hues），这反映了在官方严厉海禁（Ming Gap）的背景下，东南亚市场对中国瓷器的巨大需求迫使南方私窑将次品也投入出口市场 [2, 3]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家可在东南亚黑市低价批量购入的瑕疵贸易品。
* **Q2 异**：✓ 打破了“大明外销瓷全是精品”的刻板印象，展现了供需失衡下的下沉市场。
* **Q3 链**：✓ 链接大明民间私窑、东南亚航线、Ali 的中低端倾销主线。
* **分级**：必加（L2 商业与供应链断裂）。

## 3. 视角自查 (P1-P5)
* **亚/中视角**：在严酷的海禁政策下，民间窑工与走私商为了生存，不遗余力地填补海外市场空缺，哪怕是次品也能换回真金白银 [1, 2]。
* **东南亚视角**：对中国瓷器的极度渴求使得他们接受了这些瑕疵品，这是一种被垄断裹挟的消费降级 [2]。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Ali (利用瑕疵品进行市场倾销) / Pietro (从次品中寻找私窑的秘密分布)
* `darkLineLayer`: L2（全球贸易网络中的供需失衡与黑市洗牌）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“想在马尼拉赚钱？别去等那些完美的景德镇官窑了。去黑市找那些颜色发灰、釉面有气泡的福建瓷盘。虽然长得丑，但南洋的土王们照样愿意用成箱的香料来换！”
* **记录 (Archives Record)**：“一批打捞自 Santa Cruz 沉船的 15 世纪青花瓷 [1]。其特征是普遍存在烧制温度不均导致的釉面缺陷与发色异常 [3]。这印证了大明帝国实施‘海禁’期间，海外市场极度饥渴，促使大量未经品控的民间私窑产品涌入南中国海 [2]。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派经济备忘录】不要嘲笑这些瑕疵品。当大明的皇帝试图用一纸禁令封锁海洋时，正是这些带着气泡的粗劣瓷器维系着整个亚洲的白银与商品流转 [2]。它们是民间资本冲破帝国壁垒的粗糙切面，而我们的远洋情报网，正是靠着这些走私船得以存续。”

> **博物层分类：[留-原始信标会]** — 信标会情报网依附走私船，未涉及远古机器。
