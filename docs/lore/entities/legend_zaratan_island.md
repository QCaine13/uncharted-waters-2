# 实体档案：萨拉坦的沉没 (The Sinking Zaratan)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：阿拉伯航海神话与欧洲中世纪动物传兽集中的巨龟/海怪“萨拉坦（Zaratan）”传说 [4, 5]。
* **L2（学术）**：在古代水手的传说中，萨拉坦是一种背上长满树木的巨型海龟或鲸鱼。水手们经常将其误认为岛屿并在其背上生火，导致怪物潜入深海，将整个船员拖入水中 [6, 7]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 航海中偶尔遭遇的“伪装岛屿”迷雾事件，登岛探险可能遭遇巨大风险。
* **Q2 异**：✓ 将经典的航海怪物传说具象化为地图上动态生成的临时迷雾岛屿。
* **Q3 链**：✓ 链接阿拉伯海域神话、Ernst 的异兽图鉴、大洋深处的自然恐慌。
* **分级**：必加（L4 神秘学与生物灾难）。

## 3. 视角自查 (P1-P5)
* **阿拉伯/西方水手**：这是神罚，是对人类盲目踏足未知海域的致命陷阱 [6]。
* **理性视角**：极可能是某些被大型藻类和火山浮石覆盖的远古海洋巨兽，或特定地质活动的幻象 [7]。

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“如果在大洋中央看到一座长着棕榈树的岛屿，千万别急着上去抛锚生火！那根本不是岛，是萨拉坦！只要你的火把烫到它的背，它就会带着你和你的船一起沉进无底深渊！”
* **记录 (Archives Record)**：“自中世纪起便流传于阿拉伯和欧洲水手间的传说。怪物‘Zaratan’被描述为大到足以支撑整个生态系统的海龟或巨鲸 [6]。许多失踪的船只被归咎于误登了这种伪装成岛屿的生物 [7]。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】萨拉坦（Zaratan）不是神罚，也不是谁布下的陷阱，它是几桩寻常海象在惊惧之心里叠成的怪影。大洋上时有覆满海藻、藤壶与火山浮石的庞然之物浮于水面：或是一头背覆生态、久浮不沉的巨鲸或巨龟，或是一片被洋流聚拢、连缀着浮石与漂木的‘漂浮岛’ [6]。倦极思陆的水手把它认作小岛，登临、抛锚、生火——火灼之下，伏卧的巨兽受惊潜没，或浮石岛被涌浪一冲而散，于是连人带船一并没入深渊，幸存者归来便说那岛‘活了’、把同伴拖下了海 [7]。这是博物学能够照亮的恐惧，与海底是否藏着什么、是否有什么在‘清理入侵者’全不相干。本会记录它，只为留住这条朴素的道理：大洋里最骇人的怪物，往往是航海者把自己不解的生灵与地质，拼成了一座会沉的岛。”
