# 实体档案：船仔妈神龛 (The "Chuanzai Ma" Bow Shrine)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：明代以来南中国海中国帆船的内部结构记录，以及现存妈祖信仰的造船传统。
* **L2（学术）**：东方远洋商船上必定在主桅杆后方设有一个专属神龛（shen tang），里面供奉着一尊小型的木制妈祖像，被称为“船仔妈”（chuanzai ma，意为“船之守护神”），由船上的“司香”（Incense Master）专门负责照料 [6]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家为舰队改装（Remodel）时，可选的高级东方舰首/船内防御组件，降低灾害概率。
* **Q2 异**：✓ 与欧洲挂着十字架或木雕美人鱼的舰首像截然不同，这是一种具有东方宗教建制和专职人员管理（司香）的随船信仰实体。
* **Q3 链**：✓ 链接东亚造船厂、中国/东南亚海商、L4 航海神秘学。
* **分级**：必加（L4 神圣航海技术）。

## 3. 视角自查 (P1-P5)
* **亚洲视角**：这是整艘船的灵魂中心，是水手在无情大洋中唯一的慈悲慰藉。
* **西方视角**：不理解为何要在船舱深处供奉一个木头娃娃，将其视为东方海员心理脆弱的象征。

## 4. 钩子设计 (storyHooks)

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“那些大明来的福船，主桅杆后面总有个小黑屋，里面供着个木雕的女神像。他们叫她‘船仔妈’。我见过他们的船被巨浪拍出裂缝，但只要那小屋里的香不断，船就死活不沉！”
* **记录 (Archives Record)**：“东方远洋帆船的标准建制。在主桅后方设有名为‘神堂’（shen tang）的专属神龛，内供木雕妈祖像‘船仔妈’（chuanzai ma） [6]。船上特设‘司香’（Incense Master）一职，确保航行期间香火不断，以此维系全船水手的精神士气。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派造船档案】‘神堂’的位置绝非随意设定。主桅杆后方正是整艘木制帆船应力最集中的震颤节点。那尊被称为‘船仔妈’的木雕，其材质多选用密度极高的铁力木或沉香木。这实际上是一个质量阻尼器。当风暴来袭时，神像的微小位移能有效吸收并抵消桅杆传导下来的致命共振。所谓女神的庇护，是极其高明的力学工程。”

> **博物层分类：[留]** — 纯力学工程解释（质量阻尼器吸收共振），无机器，无普世遗产引用。darkLineLayer 字段虽写“深海防御机制”，但博物正文为纯物理。
