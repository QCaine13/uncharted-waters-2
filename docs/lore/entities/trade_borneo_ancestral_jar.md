# 实体档案：婆罗洲祖灵陶罐 (Borneo Ancestral Magic Jar)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：1997年发现的文莱（Brunei）沉船考古发掘报告，该船沉没于1500年左右的南中国海 [1]。
* **L2（学术）**：该沉船出水了大量储物陶罐。对于婆罗洲的原住民部落而言，这些舶来的中国或东南亚陶罐不仅用于装水，更在魔法仪式、丧葬习俗和祖先崇拜中扮演核心角色，被作为珍贵的传家宝世代相传 [2]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家在婆罗洲沿岸港口（如文莱）探索或贸易时可获得的高价值文化遗物。
* **Q2 异**：✓ 打破了“陶罐只是用来装水/装香料”的普遍认知，展现了土著文化对舶来品的神秘化二次赋权。
* **Q3 链**：✓ 链接文莱港口、原住民 NPC、Ernst 的人类学记录、Pietro 的文物收藏。
* **分级**：必加（L4 神秘学与文化交融）。

## 3. 视角自查 (P1-P5)
* **原住民视角**：这是祖先灵魂的居所，是沟通阴阳两界的圣物，其价值远超黄金。
* **大明/西方商贩视角**：这只是一种廉价的工业容器，原住民愿意用珍贵的香料和砂金来换取这些粗陶，是不可思议的暴利（存在认知差与剥削）。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Ernst (研究土著信仰与舶来品的关系) / Pietro (收集奇异传家宝)
* `darkLineLayer`: L4（跨文明物质崇拜的理性解构）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“在文莱的丛林里，如果你拿出一个普通的广东粗陶罐，那些浑身刺青的猎头族会跪下来亲吻它，甚至愿意用一整袋黄金来跟你换。他们说，那种罐子能把死人的灵魂装进去。”
* **记录 (Archives Record)**：“打捞自文莱海域沉船的大型粗陶罐。对于婆罗洲的内陆部落来说，这些跨海而来的陶瓷容器极其罕见。它们脱离了最初的储物功能，被原住民整合进丧葬与魔法仪式中，成为象征部落权力与祖灵庇佑的传家圣物。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】婆罗洲内陆部落肯用一整袋砂金去换一只广东粗陶罐，欧洲商贩当作不可思议的暴利，本会却以为这崇拜里藏着务实的道理。这些越洋而来的高温釉陶，胎体致密、釉面光洁、口可严封——在湿热的雨林里，它远比竹木、葛布更能隔绝潮气、虫蚁与霉腐，用来盛放骨殖、收藏圣物或封存种粮，实在是当地稀缺的耐久容器。一件能让祖先遗骨经久不坏的器皿，被尊为祖灵的居所、世代相传的传家宝，再自然不过：所谓‘魔法’，多半是这层朴素的防腐与耐用，在没有窑业的部落眼中显出的神异。本会记录它，与失落王国的遗产并无关联，只为留住跨海陶器如何在异乡被赋予全新神圣意义这桩文化交融的实例——同一只罐子，在产地是寻常炊具，在雨林深处却成了沟通生死的圣器。”

> **博物层：已按 D7 去机器改写（2026-06-14）** — 删去「绝缘矿物 / 低效法拉第笼 / 异常磁场辐射屏蔽」的机器辐射设定，改为高温釉陶在湿热雨林里实为稀缺的耐久防腐容器，故被神圣化（跨文明物质崇拜的务实根源）。原机器版见 git 历史。
