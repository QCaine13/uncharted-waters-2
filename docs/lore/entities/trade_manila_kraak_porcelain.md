# 实体档案：马尼拉的克拉克定制瓷 (Manila Kraak Porcelain)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：1600年于菲律宾海域沉没的西班牙大帆船 San Diego 号出水文物清单 [1, 2]。
* **L2（学术）**：景德镇窑工为了迎合伊比利亚买家的需求，专门制造了欧洲器型（如芥末罐、带把酒杯），但表面依旧保留中国传统的花鸟与山水纹饰，这种混血瓷器被称为“克拉克瓷” [2]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 极高价值的跨洋贸易品，马尼拉黑市限定。
* **Q2 异**：✓ 它不是纯粹的东方艺术品，而是大航海时代第一波“全球化定制”的产物。
* **Q3 链**：✓ 链接太平洋大帆船航线、Pietro 收藏线、大明走私商与西班牙总督的博弈。
* **分级**：必加（L2 商业与经济暗线）。

## 3. 视角自查 (P1-P5)
* **欧洲视角**：象征着欧洲王室和贵族对东方奢侈品的狂热，是西班牙白银霸权的体现。
* **大明视角**：民间窑口极具商业敏锐度的“降维打击”，用泥土和窑火疯狂抽干美洲的白银储备，夺回陶瓷霸权 [2, 3]。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Pietro (全球艺术品图鉴) / Ali (建立跨洋高利润航线)
* `darkLineLayer`: L2（全球白银与商品供应链暗战）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“新西班牙的贵族们全疯了。他们用成吨的波托西白银，在马尼拉换取一种画着蓝花的盘子。听说大明的工匠专门照着欧洲酒壶的形状烧制它们，轻得像纸一样！”
* **记录 (Archives Record)**：“打捞自 San Diego 号的特制青花瓷。器壁极薄，器型完全是为了适应欧洲人的餐饮习惯而定制的，但图案依然是中国传统的鹿与花卉。这是太平洋贸易巅峰期的标志物。” [2]
* **博物 (Exhibit Description)**：“【信标会内参：温和派经济备忘录】当西班牙人以为他们用火炮和白银征服了世界时，东方的窑火正在用这种极具欺骗性的定制瓷器悄悄抽干美洲的银矿。这不仅仅是贸易，这是东方文明在未动一兵一卒的情况下进行的底层经济反制，而本会的远洋资金链正是借此网络在暗中洗白。”

> **博物层分类：[留-原始信标会]** — 信标会洗白远洋资金链，未涉及远古机器。
