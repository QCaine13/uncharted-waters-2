# 实体档案：占婆亡国青瓷 (Champa Celadon of Pandanan)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：菲律宾巴拉望岛附近发掘的 Pandanan 沉船（约15世纪中叶）考古报告 [1]。
* **L2（学术）**：在大明海禁导致的“明代断层（Ming Gap）”期间，越南和占婆（Champa）的陶瓷填补了东南亚市场的巨大空白 [2]。Pandanan 沉船装载了运往东南亚的最大一批占婆青瓷，而这艘船极可能是占婆王国被北越摧毁前派出的最后一批商船之一 [1]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 稀有的绝版文化贸易品，价值随时间推移而升高。
* **Q2 异**：✓ 它代表了一个即将消亡的古老文明在贸易史上的绝唱，具有浓厚的悲剧色彩。
* **Q3 链**：✓ 链接中南半岛的政权更迭、大明海禁的连带反应、Pietro 的文物拯救主线。
* **分级**：必加（L2 商业线与地缘政治）。

## 3. 视角自查 (P1-P5)
* **东南亚视角**：占婆王国在覆灭前的最后挣扎，他们在明朝缺席的短暂窗口期内，试图通过贸易重塑国力，却最终湮灭于历史 [1, 2]。
* **大明/西方视角**：仅仅是明代瓷器缺席时的临时替代品，随着晚明私商重新出海，这些青瓷很快被遗忘 [1, 2]。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Pietro (收藏一个文明的绝唱) / Ernst (记录中南半岛的地缘剧变)
* `darkLineLayer`: L2（大国政策真空期引发的区域经济洗牌）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“你见过那种绿色的粗陶罐吗？卖它的人自称来自一个叫‘占城’的古老王国。听说北方来的大军已经烧毁了他们的首都，这可能是他们运出来的最后一船货物了。”
* **记录 (Archives Record)**：“15世纪中叶的占婆青瓷，发现于 Pandanan 沉船 [1]。由于明代海禁导致中国瓷器出口锐减，占婆和越南的窑口曾短暂地统治了南洋市场 [2]。这批青瓷品质上乘，被认为是占婆王国覆灭前最后的贸易遗存 [1]。”
* **博物 (Exhibit Description)**：“【信标会内参：极端派日志】大明帝国的贸易禁令不仅影响了白银，更间接导致了中南半岛的文明更迭 [2]。占婆试图用这些青瓷填补市场以换取军费 [1]，但失败了。这提醒我们，干预全球供应链的流向，就足以在不开一枪一弹的情况下抹除一个王国。这正是我们渴望掌握的力量。”

> **博物层分类：[留-原始信标会]** — 信标会对供应链权力的反思，未涉及远古机器。
