# 实体档案：索德雷的航海星盘 (The Sodre Astrolabe)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：阿曼 Al Hallaniyah 岛沿海发掘的葡萄牙战舰 Esmeralda 号（1503年沉没）水下考古报告 [5]。
* **L2（学术）**：这是目前已知全球最古老的航海星盘（约1496-1501年），盘面带有葡萄牙国王曼努埃尔一世的徽记 [6]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家可装备的高级测量仪。
* **Q2 异**：✓ 带有皇家徽记的军用黑科技，非普通星盘。
* **Q3 链**：✓ 链接葡萄牙皇家海军势力与制图主线。
* **分级**：必加（L3 政治与军事暗线）。

## 3. 视角自查 (P1-P5)
* **欧洲视角**：葡萄牙突破印度洋未知海域的科学利器，帝国骄傲。
* **阿拉伯/印度视角**：因为 Esmeralda 号曾无视当地渔民警告并带来杀戮，此物被视为“带来战火的青铜诅咒” [5]。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Ernst (制图精度追求) / Joao (探寻葡萄牙秘史)
* `faction`: 葡萄牙总督府 vs 阿拉伯航海家

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“达伽马的舰队之所以能在季风中活下来，是因为他们有一种刻着国王印记的黄铜圆盘。据说它能把星星的灵魂锁在里面。”
* **记录 (Archives Record)**：“一件极为罕见的早期航海星盘，打捞自1503年沉没的 Esmeralda 号残骸。盘面隐秘地铸有曼努埃尔一世的徽章，是葡萄牙严禁外流的最高级别军用仪器。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派档案】葡萄牙人以为他们掌握了星辰，但这面星盘的铸造比例，实则参考了本会在里斯本暗中放出的古希腊天球仪残卷。我们赋予他们跨越深海的技术，是为了让他们替我们测绘出‘普世遗产’的真实坐标。”
