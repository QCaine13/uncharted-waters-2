# 实体档案：千里眼与顺风耳木雕 (Idols of the Demonic Sentinels)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：明代永乐年间（1409年）收录于道藏的《太上老君说天妃救苦灵验经》 [10]；以及闽南/台湾妈祖庙的传统造像配置 [11]。
* **L2（学术）**：在东亚的海洋神话中，“千里眼”（Qianliyan，红身双角）与“顺风耳”（Shunfeng'er，绿身单角）原本是危害海上的恶魔。被妈祖（Mazu）降伏后，他们成为了妈祖在海上的耳目，帮助神明提前察觉海难 [10, 11]。在南中国海的帆船神龛中，常供奉此二将以求预警 [12]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家可装备于船只的特殊舰首像/神龛配件，提升舰队的视野范围（千里眼）与遭遇战预警率（顺风耳）。
* **Q2 异**：✓ 将东亚航海宗教中的“恶神护法”具象化为游戏内的预警雷达装备。
* **Q3 链**：✓ 链接东亚妈祖信仰、大明海商、Ernst 异国风俗记录线。
* **分级**：必加（L4 神圣航海与科技暗线）。

## 3. 视角自查 (P1-P5)
* **亚/中视角**：被神明仁慈感化的恶魔，如今用他们超越凡人的感官保护着在波涛中挣扎的水手，是妈祖神力的具象化延伸 [10, 12]。
* **西方视角**：难以理解为何要在保护神的旁边雕刻如此狰狞可怖的红绿恶魔 [11]，将其视作东方宗教诡异的象征。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Ernst (研究东方航海信仰与感官增强) / Maria (打造东方无敌舰队)
* `darkLineLayer`: L4（航海预警经验的神话化封装）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“如果你去大明的帆船上做客，除了拜那位叫妈祖的女神，别忘了给旁边那一红一绿两个妖怪上柱香。水手们说，起雾的时候，这两个怪物能隔着几百里听到暗礁的水声，看到海盗的船帆！”
* **记录 (Archives Record)**：“通常成对放置于东方帆船神龛（Shen tang）内的木雕神像 [12]。红色的被称为‘千里眼’，绿色的被称为‘顺风耳’。神话称他们原是恶魔，被海神降伏后充当了神明的雷达系统，专门在风暴与迷雾中为水手预警灾难 [10, 11]。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】西方船客不解：何以要在慈悲的海神身旁，供一红一绿两尊狰狞的护法？这恰是东亚航海神学最务实的一面。传说里，千里眼与顺风耳本是为祸海上的恶魔，被妈祖降伏后，方以其‘看得远、听得真’的本事替神明耳目——这分明是把舵手最看重的两桩本领郑重供奉起来：雾里辨帆、浪中听礁。说穿了，‘千里眼’供的是瞭望，‘顺风耳’敬的是辨音，是闽台水手把生死攸关的预警之能，封进了可膜拜、可叮嘱、可代代相传的神像里。本会留意它，不为木雕里藏着什么失传的机括，而因它又一次印证：无论东西，凡常年与大海周旋的人，都懂得把保命的经验托付给神祇与仪式，好让它不随某个老舵手的离世而失传。它不是器械，是一桩被供奉起来的航海智慧。”

> **博物层：已按 D7 去机器改写（2026-06-14）** — 删去「内部腔体声学放大 / 水晶眼折射红外 / 失落早期预警科技」的超科技归因，改为两将神像实为东亚航海对瞭望、辨音两项预警本领的神格化封存（务实的航海神学）。原机器版见 git 历史。
