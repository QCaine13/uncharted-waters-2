# 实体档案：圣本笃号的麒麟青花盘 (Qilin Porcelain of the São Bento)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：1554年葡萄牙战舰圣本笃号（São Bento）在南非特兰斯凯（Transkei）海岸惨烈触礁沉没的历史记录与打捞报告 [3, 4]。
* **L2（学术）**：考古学家从这艘葡萄牙巨舰的残骸中打捞出了极其罕见的大明正德/嘉靖年间外销青花瓷，其中最具代表性的是绘有中国神话瑞兽“麒麟”（Ch'i-lin/Qilin）图案的瓷盘 [5]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ Joao 或 Ali 路线在探索好望角至南非东海岸时，可触发的沉船打捞遗物。
* **Q2 异**：✓ 葡萄牙战舰 + 南非危险海岸 + 大明神兽瓷器，这三者的结合极具大航海时代的全球化空间张力。
* **Q3 链**：✓ 链接葡萄牙东印度航线、南非地理发现、Joao 的沉船追寻线。
* **分级**：必加（L3 航海阴谋与全球航线）。

## 3. 视角自查 (P1-P5)
* **葡萄牙视角**：这是帝国航海悲剧的见证，满载着东方财富的巨舰最终没能敌过好望角的狂风。
* **大明视角**：江南民窑出产的瑞兽纹饰，成为了西方人葬身海底的陪葬品。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Joao (追寻葡萄牙海军失踪之谜) / Ali (寻找沉没的东洋财富)
* `darkLineLayer`: L3（航线垄断与航海灾难的内幕）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“南非那片见鬼的海岸吞噬了无数葡萄牙巨舰。听说最近有人在沙滩上捡到了蓝白相间的瓷片，上面画着长鳞片的东方喷火怪兽。水手们都说，是那种怪兽引来了好望角的风暴！”
* **记录 (Archives Record)**：“一件出水自 1554 年圣本笃号（São Bento）沉船残骸的大明青花瓷盘。盘心绘有被火焰环绕的瑞兽‘麒麟’（Ch'i-lin）。这证明了早在 16 世纪中叶，中国高级瓷器就已成为葡萄牙帝国在印度洋航线上的核心运输财富 [5]。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】水手把圣本笃号的覆灭推给盘上的麒麟，是把好望角那段海岸的脾气错记在了一尾瑞兽身上——那一带本就乱流、暗礁、季风骤转，吞过的葡萄牙巨舰何止一艘，与谁的船舱里装着什么并无干系。本会真正在意的，是这尾被火焰环绕的麒麟本身：它是江南民窑应外销之需画给番邦的祥瑞，可那环身的火焰、四向放射的纹路，与我们在东非、印度沿海记录的景教遗物星象母题隐隐相通。极端派据此疑心大明窑工早受过失落王国的余泽，主张把这批瓷器尽数收没封存；我们温和派以为不必如此——东方的窑工、地中海的僧侣，各自膜拜不同的神，却不约而同把光与星辰刻进至贵之物，未必是谁传给了谁，更可能是那些景教传教者走得比帝国史书所愿承认的更早、更远。这只盘子不是死亡坐标，是一段被海水冲散的家书残页。”
