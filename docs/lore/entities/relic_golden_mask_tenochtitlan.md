# 实体档案：特诺奇蒂特兰金面具 (Golden Mask of Tenochtitlan)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：1521年阿兹特克帝国首都特诺奇蒂特兰（Tenochtitlan）陷落后的原住民纳瓦特尔语（Nahuatl）残存抄本 [5]。
* **L2（学术）**：西班牙征服者埃尔南·科尔特斯在征服中美洲时，熔毁了海量的原住民黄金艺术品。但在原住民的秘密记录中，有极少数代表太阳神崇拜的最高级圣物被祭司在城破前带离并藏匿 [5]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家作为 Joao/Pietro 路线深入美洲内陆遗迹获取的顶级宝物 [5]。
* **Q2 异**：✓ 美洲印第安文明的顶级圣物，与欧亚基督教传统形成强烈的跨文化冲击 [5]。
* **Q3 链**：✓ 链接加勒比港口、中美洲丛林探索线、信标会 L5 终局秘密 [5]。
* **分级**：必加（L5 终局真相与普世遗产）。

## 3. 视角自查 (P1-P5)
* **美洲原住民视角**：以祭司的悲剧性视角，记录了神圣祖先面具在侵略者贪婪之火中的幸存，是文明最后的尊严 [9]。
* **欧洲视角**：西班牙修士在忏悔录中视其为“异教徒的邪恶偶像”，但在熔炉中无法融化使其沾染了恐怖的色彩 [9]。

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“那些从新西班牙回来的水手喝醉了都在说胡话。他们说在特诺奇蒂特兰的废墟下，藏着一张属于羽蛇神的金面具。西班牙人曾经抓住过它，把它扔进熔炉里，结果面具不但没化，还在火里发出了恐怖的尖叫！”
* **记录 (Archives Record)**：“一件躲过了 1521 年西班牙征服者大熔炉的阿兹特克纯金面具。根据幸存的纳瓦特尔语抄本记载，城破之日，最高祭司将其带入雨林深处。其造型不仅体现了中美洲极高的冶金工艺，面部线条更是充满了对天文星象的崇拜。”
* **博物 (Exhibit Description)**：“【信标会内参：美洲分部考据】（温和派誊本）不要被熔炉里尖叫的传说迷惑——面具未熔，多半因为它并非纯金，而是中美洲常见的「tumbaga」金铜合金，表层富金、内里熔点更高，征服者的炉火不足以化尽。真正让本会驻足的，是它背面的几何纹样：那组以太阳为心、向四方放射的刻线，与我们在东非、印度沿海所记录的景教遗物星象母题惊人相似。极端派据此断言此乃同源文明须收没销毁的铁证；我们温和派以为不必如此惊惧——美洲的祭司、明朝的窑工、地中海的僧侣膜拜着不同的神，却不约而同地把太阳与星辰刻进至圣之物。这未必是谁「植入」了谁，更可能是那些失落王国的传教者，比任何帝国的史书所愿承认的，走得更早、更远。这面具不是机括，是一封迟到了三百年的家书。”
