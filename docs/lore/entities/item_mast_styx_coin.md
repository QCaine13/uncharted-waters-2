# 实体档案：主桅下的冥河银币 (The Styx Coin under the Mast)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：欧美帆船制造的悠久传统（Mast stepping ceremony） [9]。
* **L2（学术）**：水手在建造新船安置主桅杆时，必须在桅杆底部压一枚金币或银币。这一迷信源自古罗马时期为死者口中含硬币的习俗，目的是为了在船只沉没时，水手有钱支付给冥河渡神卡戎（Charon） [10]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家在造船厂定制新船时可选的特殊仪式（消耗金币，提升该船在风暴中的抗沉属性）。
* **Q2 异**：✓ 将欧洲造船的硬核迷信具象化为游戏机制。
* **Q3 链**：✓ 链接欧洲各大造船厂、海上灾难事件、Catalina 的战舰强化。
* **分级**：必加（L4 神秘学与海洋恐惧）。

## 3. 视角自查 (P1-P5)
* **欧洲视角**：这是对不可预知的海洋力量的敬畏，是航海人之间不言自明的悲壮契约 [9, 10]。
* **理性/现代视角**：一种徒劳的心灵安慰剂，或者单纯是造船工匠骗取额外赏钱的把戏。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Catalina (打造无敌战舰) / Joao (初次造船的仪式体验)
* `darkLineLayer`: L4（海洋超自然恐惧的理性投射）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“如果你找那个热那亚的老船匠造船，千万别省那一枚压在主桅杆底下的银币！海洋总是要收过路费的，如果船底没有硬币，它就会收走你们的命来代偿！”
* **记录 (Archives Record)**：“欧洲造船业的一项古老传统。工匠在竖立主桅之前，会在桅座下放置一枚硬币。水手们迷信地认为，如果船只不幸沉没，这枚硬币将作为支付给冥河渡神的船资。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】桅座下那枚硬币，谈不上什么深海的机括或暗中的操弄。它是一条从古罗马一路漂流到风帆时代的旧俗：罗马人为死者口中含币，好让亡魂付得起冥河渡神卡戎的船资；造船的匠人把这念头压进新船的龙骨，便成了一艘船与海洋之间不言自明的契约——倘有沉没的一天，船上人也不至于赤手空拳去见那位摆渡者。本会把它收入档案，不为它能驱动什么，而为它是一面镜子：地中海的水手怕债欠冥河，东方的舵手向妈祖抛纸船，西非的航者另有自己的禳解——天各一方的人，面对同一片吞噬性命的大海，都本能地想用一件小物、一桩仪式，为不可知的命运换得一分体面与安宁。这枚银币不通往任何遗产，它只通往人心那点共通的、对深渊的敬畏。”

> **博物层：已按 D7 去机器改写（2026-06-14）** — 删去「银铜合金压电效应 / 普世遗产自卫系统误判」的机器设定，改为如实溯源古罗马冥河渡资旧俗，并以多文明同类禳解仪式的并置呼应人类共通的海洋敬畏。原机器版见 git 历史。
