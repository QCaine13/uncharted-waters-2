# 实体档案：德尔纳特黄金丁香 (Golden Clove of Ternate)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：16世纪初香料群岛（摩鹿加群岛）德尔纳特苏丹国（Ternate）与伊比利亚人的接触记录 [8]。
* **L2（学术）**：为了争夺高额利润的丁香，西班牙和葡萄牙在香料群岛展开了激烈争夺。两国传教士和殖民者通过向当地火山苏丹国赠送重金礼品、进行盟誓，以获取排他性的香料采购权 [8]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ Ernst（制图）或 Ali（商债）在东南亚获取，用于解锁香料群岛特定港口的极高价值交易权 [8]。
* **Q2 异**：✓ 这是直接具象化“香料比黄金更贵”这一大航海时代底层逻辑的圣物 [8]。
* **Q3 链**：✓ 链接 Ternate 港口、Banda 港口、欧洲联合商会的暗中角力 [8]。
* **分级**：必加（L4 全球香料垄断与神秘遗存）。

## 3. 视角自查 (P1-P5)
* **东南亚视角**：当地苏丹国在两大欧洲强权间巧妙周旋、待价而沽的自主外交智慧的信物 [8]。
* **欧洲视角**：在欧洲征服者的日记里，这被轻蔑或自大地描述为“土著苏丹用于表示臣服的贡物” [8]。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Ali (夺取香料群岛的垄断权) / Ernst (揭开火山群岛的真实地貌)
* `darkLineLayer`: L4（香料垄断背后的失落王国遗存）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“想要在德尔纳特买到满船的丁香？你得先让苏丹看一眼传说中的‘黄金丁香’。据说那是当年白人传教士为了讨好土王，用纯金一比一打造的。只要拿着它，你就是火山岛上尊贵的客人！”
* **记录 (Archives Record)**：“一枚由高纯度黄金精心雕刻而成的丁香花蕾模型。16世纪初，随着《萨拉戈萨条约》的签订，葡萄牙与西班牙在摩鹿加群岛展开了残酷的香料暗战。这件黄金器物极有可能是双方为了换取德尔纳特苏丹独家供货权而铸造的盟誓信物。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】把这枚黄金丁香说成‘讨好土王的贡物’，是低估了德尔纳特苏丹。在葡萄牙与西班牙为丁香撕咬、《萨拉戈萨条约》把摩鹿加群岛劈成两半的年月里，一个火山岛上的小苏丹国能在两大强权之间反复待价而沽、毫发无损地保住独家供货权，靠的不是哪国的恩赏，而是极精明的自主外交——这枚以纯金一比一打造的丁香，正是这种周旋本身的信物：谁想换取排他采购权，就得先在它面前立誓。本会留意它，是因为它的工艺：那向四周绽开的金质花蕾，刻线规整、向心放射，与我们在东非、印度沿海记录的景教遗物星象母题颇有几分神似——或许是经由印度洋商路辗转传入的纹样母题。极端派据此疑心香料群岛也曾沾染失落王国的余泽，主张连同采购权一并掌控；我们温和派以为不必牵强：一枚信物能讲清两件事就够了——东南亚苏丹国在列强夹缝中的外交智慧，以及那些景教纹样比帝国史书所愿承认的，飘散得更远。它不是开启什么的钥匙，是一座小岛守住自己的凭证。”
