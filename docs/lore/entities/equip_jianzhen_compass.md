# 实体档案：监针童子罗经盘 (Compass of the Needle-Supervising Boy)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：明代航海针经《顺风相送》与清代《指南正法》中的祷文记录 [11, 12]。
* **L2（学术）**：中国水手不仅使用磁罗盘，还会将指南针以及造船术神格化。他们在航海科仪中会向木匠祖师“鲁班”以及司掌指南针的“监针童子”祈祷，以确保航向不偏 [11, 13]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家可装备的高级航海道具，提升东亚/太平洋海域的航行精度，减少迷航率。
* **Q2 异**：✓ 带有东方神灵信仰（鲁班/监针童子）的科技仪器，与欧洲星盘形成鲜明对比 [11]。
* **Q3 链**：✓ 链接大明航海科技、Ernst 的制图线、以及东亚水手 NPC。
* **分级**：必加（L3 科技暗线）。

## 3. 视角自查 (P1-P5)
* **亚/中视角**：将精密科学与敬畏神明完美结合的航海重器，是指引船只在茫茫大洋中平安归来的守护者 [14]。
* **欧/西视角**：难以理解为什么要把一个物理仪器拟人化，认为这是一种过度迷信。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Ernst (追求不同的导航流派) / Maria (寻找东方的航海黑科技)
* `darkLineLayer`: L3（东西方航海科技树的分歧）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“大明的领航员都在船上供奉着一个叫‘监针童子’的神仙。他们说罗盘里住着一个小精灵，只要你诚心祈祷，哪怕在连月亮都看不见的浓雾里，它也能带你找到港口！”
* **记录 (Archives Record)**：“一件制作精良的东方水旱罗经盘。盘面上不仅刻有天干地支二十四方位，其外壳还用朱砂写着向‘鲁班’和‘监针童子’祈求的密咒。这是东方领航员（火长）视若生命的法器。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派档案】东方人将地磁偏角的物理现象拟人化为了‘监针童子’的调皮。罗盘上刻写的那些冗长祈祷文，实际上是一套严格的倒计时口诀，用于在不同纬度下校准地磁异常。他们用神学的语言，完美封装了最高级别的航海物理学。”

> **博物层分类：[留]** — 纯自然解释（地磁偏角、纬度校准口诀），无机器，无信标会。
