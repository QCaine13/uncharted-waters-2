# 实体档案：唤风的口哨 (The Whistling Wind Taboo)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：欧美帆船时代的古老航海禁忌（Nautical superstitions） [8, 9]。
* **L2（学术）**：几个世纪以来，水手们严禁在船甲板上吹口哨。他们迷信地认为，吹口哨是对风神的挑衅，会“唤醒风暴”（whistling up a storm）带来灭顶之灾 [8, 9]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 船员士气管理机制，当船员忠诚度极低时触发的负面事件（船员因有人吹口哨而恐慌哗变）。
* **Q2 异**：✓ 生动展现了欧洲风帆时代底层水手的精神状态与极端环境下的心理投射 [8]。
* **Q3 链**：✓ 链接航海士气系统、极端天气生成机制、西方水手 NPC。
* **分级**：可选，但极具沉浸感（L4 神秘学与心理学）。

## 3. 视角自查 (P1-P5)
* **欧洲水手视角**：海洋是喜怒无常的神明，任何轻浮的哨声都会招致可怕的报复 [8]。
* **科学/信标会视角**：人在孤立无援的深海中产生的心理暗示与幸存者偏差。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Joao (初出茅庐的船长需要安抚迷信的船员) / Otto (铁血镇压哗变)
* `darkLineLayer`: L4（海洋恐惧的心理学解构）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“闭嘴，新来的！把你的嘴唇缝上！在甲板上吹口哨，风神会以为你在挑战他。上一个这么做的白痴，第二天就把全船带进了一场卷走主桅杆的飓风里！”
* **记录 (Archives Record)**：“西方风帆时代最根深蒂固的航海迷信之一。各国海军与商船均有不成文的规定：严禁水手在海上吹口哨，因为这被认为会‘召唤风暴’ [8]。唯一被允许吹口哨的是船上的炊事兵，因为只要他在吹口哨，就证明他没有偷吃食物 [8]。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】‘吹口哨会唤来风暴’，根子全在人心，与海上的任何异常无干。一支船队孤悬大洋，性命系于风之有无，水手便把这份无从掌控的焦虑，统统投向了喜怒无常的‘风神’：吹哨是轻佻的挑衅，触怒了他便招来灭顶之灾。这是一种典型的幸存者错觉——成千上万次甲板上的口哨之后什么也没发生，无人记得；偏偏某次哨声后果真起了风暴，便被人牢牢记住、辗转相传，禁忌就此铸成。至于唯独炊事兵获准吹哨，更是把禁忌用作了管理之术：只要哨声不断，便知他没在偷吃。本会留存此条，与磁场、共振之类毫不相干，只为记下风帆时代水手的精神图景：在孤立无援的深海里，人需要给不可控的命运安一个可触怒、也可安抚的名字，好让恐惧有处安放。”

> **博物层：已按 D7 去机器改写（2026-06-14）** — 删去「接近普世遗产的异常磁场区 / 声学共振催生气流突变」的机器气象归因，改为唤风口哨禁忌的心理学解构（焦虑投射 + 幸存者错觉 + 禁忌的管理用途）。原机器版见 git 历史。
