# 实体档案：莱纳滩走私象牙 (Lena Shoal Elephant Tusks)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：菲律宾巴拉望岛附近发掘的 Lena Shoal 沉船（1490年代）出水文物清单。
* **L2（学术）**：在这艘装载了 5000 多件大明青花瓷的沉船中，除了瓷器和金属器外，还发现了大批量的象牙（Elephant tusks）。这表明 15 世纪末的南中国海贸易网络不仅交易手工业品，还广泛涉及高价值的跨国野生动物制品（可能是从东南亚内陆或非洲运往中国市场）。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家可打捞或在黑市交易的极高价值奢侈品，有很高的利润空间但也极易招致海盗。
* **Q2 异**：✓ 这是古代全球化贸易中最血腥、最具自然剥削色彩的商品之一，补充了海洋贸易的阴暗面。
* **Q3 链**：✓ 链接黑市交易系统、大明/东南亚奢侈品需求、海盗打劫事件。
* **分级**：必加（L2 灰色商贸与全球掠夺）。

## 3. 视角自查 (P1-P5)
* **大明/买家视角**：这是雕刻佛像和贵族印章的最顶级材料，每一根都价值连城。
* **生态/被掠夺者视角**：为了满足远方帝国的贪婪，丛林中倒下了无数头巨兽。这是用鲜血浇筑的贸易。

## 4. 钩子设计 (storyHooks)

* `darkLineLayer`: L2（全球化早期的资源榨取与走私网络）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“听说巴拉望岛附近沉了一艘大船。别管那些碎瓷片了！船舱最底下压着几十根比人还高的象牙！只要能捞上一根偷偷运回大明，你下半辈子就可以在江南买座园子享福了！”
* **记录 (Archives Record)**：“打捞自 15 世纪末 Lena Shoal 沉船的象牙原木。大航海时代早期的南中国海不仅流通着陶瓷和香料，同样存在着庞大且残酷的野生动物制品贸易。这些象牙通常由东南亚或印度洋沿岸产出，作为顶级奢侈品走私进入大明帝国。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】奢侈品的流向，就是资本的流向。大明的贵族摩挲着精雕的象牙佛像与印章，多半不曾想，把这些象牙从东南亚内陆、从东非海岸一路偷运进帝国的走私网，有一段正握在本会手里。本会无意洗白这桩贸易：为满足远方帝国的贪欲，丛林里倒下了无数巨兽，这是用鲜血浇筑的生意。本会借这笔见不得光的暴利，在马六甲与月港之间悄然维系着一支不挂任何国王旗号、不受任何海关盘查的船队——它存在的理由，是为追索那些散落四海、随时可能被列强抢夺或损毁的失落王国遗存，留一条不受帝国掣肘的转运暗线。极端派主张干脆用这支船队垄断、劫夺遗产；我们温和派只想让它在风暴里护住几片残片、把它们安然送抵能被登记、被后世看见的地方。这堆象牙照见的，是全球化最初的血腥，也是本会自己难以摆脱的两难。”

> **博物层：已按 D7 去机器改写（2026-06-14）** — 删去「随时准备应对普世遗产的苏醒」（机器自我觉醒前提），保留信标会借象牙走私暴利维系影子船队这一元素，并把其目的重锚为追索/护送失落王国遗存（温和派 vs 极端派）。原机器版见 git 历史。
