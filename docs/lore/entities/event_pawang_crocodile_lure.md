# 实体档案：帕旺的巨鳄寻物 (Pawang's Crocodile Retrieval)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：马来西亚彭亨（Pahang）及吉打（Kedah）地区流传的土著巫师（Pawang）口述传统 [7]。
* **L2（学术）**：在马来口头传统中，Pawang（萨满/巫师）不仅能治病，还能念诵真言（Mantras）请求水鬼召唤鳄鱼。据称，这种被召唤的鳄鱼不仅能惩罚罪人，还能从深水里找回失落的物品，“哪怕是掉进水里的针也能捞回来” [7]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家在东南亚海域因风暴或海战损失货物/道具后，可在当地酒馆触发的特殊找回事件（需支付高额酬金给巫师）。
* **Q2 异**：✓ 突破了常规的“打捞”机制，引入了极具东南亚色彩的“巨兽寻物”灵异事件。
* **Q3 链**：✓ 链接东南亚内河港口、土著灵媒信仰、Pietro 的寻宝机制。
* **分级**：必加（L4 生物控制与神秘学）。

## 3. 视角自查 (P1-P5)
* **东南亚视角**：Pawang 拥有与自然界顶级掠食者沟通的古老智慧，这是本土文化力量的展现。
* **欧洲视角**：完全无法相信的东方魔术，或者是某种驯兽师的低级把戏。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Pietro (利用土著法术寻回沉水宝物) / Ali (见证家乡的古老神秘力量)
* `darkLineLayer`: L4（人鳄共处的在地知识神秘化）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“你的金表掉进彭亨河里了？别找白人潜水员，去红树林里找个叫‘帕旺’（Pawang）的巫师。他只要在岸边念几句咒语，第二天就会有一条三丈长的鳄鱼游过来，把你的表吐在沙滩上！”
* **记录 (Archives Record)**：“马来半岛一种奇特的萨满（Pawang）仪式。据文献记载，巫师通过念诵祈求水魔的真言，能够召唤特定的大型鳄鱼。当地人深信，这些巨鳄受巫师驱使，能够从浑浊的深水中找回失落的物品，甚至是极为细小的铁针 [7]。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】欧洲人把帕旺（Pawang）召鳄寻物斥为东方魔术，是既不懂河，也不懂人。彭亨、吉打的河口红树林本就是巨鳄的领地，世代与水为生的 Pawang 比谁都熟悉它们的脾性：哪个深潭住着哪条老鳄、它何时巡游、嗅得见何种气味、会被河岸何处的动静引来——这是一整套靠观察与禁忌累积下来的在地知识，被庄重地包进祈水神的真言里。一件金表沉入浑浊的深水，潜水的番人找不着，惯于在河底翻搅觅食的巨鳄却可能把它连泥带物拱上浅滩；Pawang 知道在何处、以何法诱使它来，于是‘巨兽衔物而还’的奇迹便成了。这里没有受什么污染而变异的怪鳄，也没有可号令生灵的秘术，只有一个民族与最凶猛的邻居长久周旋所磨出的本事。本会记录它，不为追查什么控制之法，只为它提醒我们：被斥为‘巫术’的，常常不过是别处的人比我们更深地读懂了自己的土地。”
