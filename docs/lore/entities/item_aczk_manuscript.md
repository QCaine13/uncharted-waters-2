# 实体档案：《安船酌献科》与司香航海日志 (ACZK Maritime Manuscript)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：现藏于大英图书馆的福建海澄（月港）道教航海科仪手稿（编号 OR12693/18），名为《安船酌献科》 [1]。
* **L2（学术）**：明清时期的远洋帆船上常设“香公”（Incense Master）一职，专门负责船上的神明祭祀与科仪 [2]。这份手稿不仅记录了仪轨，还在附录中记录了横跨南海的航线与各地的守护神灵 [1, 3]。

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“那些福建来的大帆船上，总有一个什么活都不干、只管烧香念经的人。他们手里有本破书，据说里面画的海图不是看星星的，而是看龙和水鬼的脾气的！”
* **记录 (Archives Record)**：“一本源自大明月港的航海科仪手稿《安船酌献科》。书中详细规定了‘香公’在海上应执行的祭祀仪式，其附录更是一份极其精确的南海航线图，标明了每个暗礁和港口对应的神灵。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】欧洲水手讥讽《安船酌献科》是‘祈求魔鬼的通行证’，是只看见了香火，没看懂香火背后那本附录。把每一处暗礁、急流与可泊之港，都系在一位守护神的名下，是东方水手用神圣地理学的形式，把世代血泪换来的航路经验编成了便于记诵、不易失传的口诀——‘呼唤某位神明’，其实是在提醒舵手：到了该转向、该避礁的水域了。它是一部裹着科仪外衣的南海航路志，未必比我们的罗盘逊色。本会珍藏它，不为它藏着什么深海禁区，而因它印证了一件事：在欧洲制图学用经纬度切分海洋之前，东方早已有另一套同样精密、却以神灵命名的海洋知识体系。极端派想把这类异质航海典籍尽数收入密库、不令外传；我们温和派主张誊录登记——因为这些散落各文明的航海智慧拼到一处，才看得出人类丈量同一片大洋时，本是殊途同归。”
