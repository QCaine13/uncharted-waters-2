# 实体档案：“中国船”的太平洋暗流 (The "Nao de China" Pacific Route)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：1565年至1815年间，连接菲律宾马尼拉与新西班牙（墨西哥）阿卡普尔科（Acapulco）的“马尼拉大帆船”（Galeón de Manila）贸易航线 [8]。
* **L2（学术）**：由于这批横跨太平洋的西班牙大帆船满载的主要是大明帝国出产的丝绸和瓷器，因此在美洲它们被统称为“中国船”（Nao de China） [8]。这条航线极其险恶，往返需要精准掌握太平洋的洋流和季风系统。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 隐藏的跨洋航线机制。只有掌握特定季风情报（或拥有航海图），才能在不饿死的情况下横跨广袤的太平洋。
* **Q2 异**：✓ 这是人类历史上第一条真正的“全球化”直接纽带，将亚洲商品与美洲白银直接挂钩，跨越了欧洲本土。
* **Q3 链**：✓ 链接马尼拉港、阿卡普尔科港、Catalina 劫掠西班牙宝船的主线、Ernst 的终极航线测绘。
* **分级**：必加（L2 经济与地缘暗战）。

## 3. 视角自查 (P1-P5)
* **大明视角**：大明民间资本通过这条洋流，将过剩的丝绸瓷器产能转化为源源不断流入帝国的白银。
* **西班牙视角**：帝国王冠上最耀眼的明珠航线，虽然凶险，但利润足以支撑整个欧洲的霸权。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Catalina (拦截世界上最富有的宝船) / Ernst (挑战太平洋季风带)
* `darkLineLayer`: L2（全球白银循环与大洋地理学）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“新西班牙的商人们都在盼着那艘被叫做‘Nao de China’（中国船）的巨大帆船靠岸。听说它要在大洋上漂泊半年！只要船长找准了那股神秘的向东吹的风，一船的丝绸就能换回整座山的白银。”
* **记录 (Archives Record)**：“马尼拉大帆船（Galeón de Manila），又称‘中国船’ [8]，是横跨太平洋的皇家贸易船队。它们将亚洲（主要是明朝）的奢侈品运往美洲，再将海量的新大陆白银运回马尼拉。这条航线的发现，奠定了长达两个多世纪的早期全球化经济基础。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】西班牙人自夸是他们‘发现’了这条向东折返的跨洋航路，其实他们摸索出的，不过是北太平洋那股早已存在的黑潮（Kuroshio）暖流与高纬西风——大洋的脉络本就在那里，谁肯一次次拿性命去试，谁就能读懂它。‘中国船’（Nao de China）由此把马尼拉的大明丝绸瓷器与阿卡普尔科的新大陆白银直接系在一起，跨过了欧洲本土，铸成人类第一条真正环球的贸易纽带。本会留意这条航路，与什么遗产的‘能源’毫不相干：散落四海的失落王国遗存，原也是顺着这类季风与洋流，在各文明间漂流、辗转的；当美洲的白银、大明的瓷器、印度洋的香料第一次在同一条航线上彼此交换，那些被各自供奉了几百年的残片，也就被商路一片片送到了彼此眼前。极端派想垄断这条银线、借它的财富抢先搜罗遗产；我们温和派只想如实把它记下来——因为这条航路真正的分量，在于它头一回让相隔半个地球的人，发现自己原来共用着同一片大洋。”

> **博物层：已按 D7 去机器改写（2026-06-14）** — 删去「普世遗产以重金属为能源 / 复苏计划」的机器设定，改为黑潮暖流与西风带的自然航海史实，并将信标会的兴趣重锚为商路把失落王国遗存彼此送回的同源主旨（温和派 vs 极端派）。原机器版见 git 历史。
