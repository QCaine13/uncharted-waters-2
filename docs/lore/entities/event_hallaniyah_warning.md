# 实体档案：哈拉尼亚渔民的警告 (The Al Hallaniyah Warning)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：阿曼（Oman）沿海哈拉尼亚岛（Al Hallaniyah）外发掘的葡萄牙战舰 Esmeralda 号沉船考古档案。
* **L2（学术）**：1503 年，达伽马第二次远航印度的舰队中，由其舅舅指挥的 Esmeralda 号停泊在阿曼海岸。当地阿拉伯渔民警告葡萄牙人，极其可怕的夏季风暴即将袭来，劝其立刻转移到避风港。但傲慢的葡萄牙指挥官无视了异教徒的警告，最终导致巨舰在风暴中粉身碎骨。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 玩家在中东/印度洋港口若无视本地 NPC 的气象警告强行出海，将遭遇致命的满级风暴惩罚。
* **Q2 异**：✓ 将“欧洲中心主义的傲慢”具象化为导致灾难的游戏机制。
* **Q3 链**：✓ 链接中东港口天气系统、葡萄牙海军霸权、Joao 沉船探索线。
* **分级**：必加（L3 帝国傲慢与地缘冲突）。

## 3. 视角自查 (P1-P5)
* **阿拉伯/中东视角**：这些驾着大船、拿着火炮的红毛野蛮人，以为自己能征服海洋，却连我们本地渔民祖祖辈辈看天象的常识都不屑一顾。海神给了他们应得的惩罚。
* **葡萄牙视角**：为了帝国的荣耀和香料，我们不能在异教徒的港口里退缩，哪怕那是风暴之主的陷阱。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Joao (探寻帝国早期的惨痛教训) / Ali (目睹西方舰队的覆灭)
* `darkLineLayer`: L3（文化偏见导致的生存灾难）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“那些傲慢的葡萄牙人！当年达伽马的叔舅就停在我们的岛外，村里的老渔民告诉他‘黑云吃月’，风暴马上就来，让他们赶紧进港。他居然骂我们是骗子，结果第二天，他的战舰连一块完整的木板都没剩下！”
* **记录 (Archives Record)**：“1503 年 Esmeralda 号在阿曼哈拉尼亚岛覆灭的灾难记录。尽管随船日志佚失，但多方史料印证，葡萄牙指挥官曾收到当地阿拉伯渔民关于夏季极端季风的明确警告。欧洲征服者对本土海洋知识的傲慢与轻视，是导致这次早期航海灾难的直接原因。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派地理备忘录】这场沉没被伪装成了自然灾害，但其实是本会阿拉伯分部的一次成功干预。当地的渔民（我们的外围眼线）给出的警告，实则是心理学上的‘逆反诱导’。他们深知葡萄牙指挥官极其自大，越是警告危险，对方就越会为了彰显武力而原地驻扎。我们借季风之手，除掉了这艘威胁本会中东补给线的旗舰。”

> **博物层分类：[留-原始信标会]** — 信标会以渔民眼线施行逆反诱导心理战，未涉及远古机器。
