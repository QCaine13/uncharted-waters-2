# 实体档案：绝境中的“妈祖”呼唤 (The Taboo of Mazu's Formal Titles)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：明代以来道教航海科仪手稿与闽粤民俗记录。
* **L2（学术）**：在中国海员的信仰中，存在一个极其特殊的禁忌：在海上遭遇紧急灾难时，绝对不能用朝廷册封的正式头衔（如“天后” Tianhou 或“天妃” Tianfei）来祈求女神的庇护 [3]。水手认为，听到正式头衔，女神会觉得必须穿戴整齐、梳妆打扮才能下凡，从而耽误救援 [3]。因此，绝境中只能大喊“妈祖”（Mazu，意为母亲） [3]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 灾难事件中的选择分支。若玩家选择了大喊“天后保佑”，会导致全船士气崩溃或救援延迟。
* **Q2 异**：✓ 这种“危机时刻不准用尊称”的底层逻辑，生动反映了民间信仰中神明的人性化与亲情化。
* **Q3 链**：✓ 链接东亚航海事件、Mazu 信仰网络、信标会的声学理论。
* **分级**：必加（L4 神秘学与民间声学的交织）。

## 3. 视角自查 (P1-P5)
* **亚洲视角**：女神如同母亲一般，听到孩子直呼“妈妈”的惨叫，连鞋都不穿就会冲过来救人。
* **西方视角**：荒谬的东方神学逻辑，神明居然还需要时间来化妆？

## 4. 钩子设计 (storyHooks)
* `protagonist`: Ali (在东亚海域的生存智慧) / Ernst (研究东亚神明的世俗化与人性化)
* `darkLineLayer`: L4（民间信仰中神明的人性化）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“记住了，起大风浪的时候，千万别喊‘天后娘娘救命’！你得用最大的力气喊‘妈祖’！你喊天后，她老人家还得回宫里换衣服戴皇冠，等你淹死了她都没下凡！”
* **记录 (Archives Record)**：“南中国海域一项奇特的航海禁忌。在紧急情况下，船员被严禁使用天妃、天后等官方尊称来祈祷 [3]。他们认为这会迫使女神换上正式的朝服而延迟援助 [3]；相反，直接呼唤‘妈祖’能换来如母亲般迅速的解救 [3]。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】西方人觉得‘神明还要换衣化妆’的说法荒谬，是没听懂这条禁忌真正在说什么。绝境里只许直呼‘妈祖’、不许用‘天后’‘天妃’这些朝廷尊封，道理朴素得很：尊号唤起的是高踞庙堂、需正冠才肯现身的女神，‘妈祖’（意为母亲）唤起的，却是听见孩子惨叫便会赤脚奔来的母亲——危难当头，人要的不是一位威严的神祇，而是一位会立刻冲过来的至亲。从声口上说，‘妈—祖’两个短促音节，确也比绵长的官称更容易在台风的轰鸣里喊得出、传得开，几十人齐声呼喊时尤其如此；但这只是它好用的缘由，不是海底有什么在应答。这条禁忌真正保存下来的，是民间信仰里一桩动人的事：百姓把至高的海神，亲手改写成了自己的母亲。本会记录它，不为追究什么频率，只为它道破了人神之间最柔软的那层关系。”
