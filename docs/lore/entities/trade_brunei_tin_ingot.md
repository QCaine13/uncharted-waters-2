# 实体档案：吉打锡币/锡锭 (Kedah Tin Ingots)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：1997年发现的文莱（Brunei）沉船考古发掘报告，该船沉没于1500年左右的南中国海 [8]。
* **L2（学术）**：该沉船出水了 128 枚 15至16世纪马来半岛特有的“锡币/锡锭”（tin-currency），是东南亚早期区域性贸易的硬通货 [9]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 东南亚专属的特殊贸易品/硬通货，可用于在特定土著港口交易高价值香料。
* **Q2 异**：✓ 打破了“全世界都只认欧洲金银币”的刻板印象，展现东南亚独立的金融生态。
* **Q3 链**：✓ 链接马六甲/文莱商业网、Ali 的政治经济主线。
* **分级**：必加（L2 商业阴谋）。

## 3. 视角自查 (P1-P5)
* **东南亚视角**：这是基于本土丰富锡矿资源建立的成熟区域性信用货币体系 [9]。
* **明朝/欧洲视角**：试图用丝绸或白银将其挤出市场，从而夺取香料群岛的定价权。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Ali (建立跨国商债网络) / Pietro (收集古代货币)
* `faction`: 东南亚苏丹国 vs 欧洲垄断商会

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“如果你想在文莱或者亚齐买到最上等的胡椒，光有西班牙的银币可不行。你得先去找本地商人换那种沉甸甸的、刻着奇怪花纹的锡块。”
* **记录 (Archives Record)**：“15至16世纪马来半岛及周边广泛流通的锡质货币。它们不仅是商品，更是连接南中国海各个苏丹国与部落的金融命脉，大航海初期的贸易均以此为锚定物。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派经济备忘录】欧洲人以为凭借火炮和白银就能控制香料，但东南亚本土的锡币系统是一堵无形的金融高墙。本会早年正是利用铸造这些锡锭的隐秘配方，在东南亚诸国中建立起了深厚的情报网。”
