# 实体档案：马来飞头蛮诅咒 (Curse of the Penanggal)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：马来世界（Malay World）广泛流传的古老鬼神民俗（Ghostlore）。
* **L2（学术）**：在马来传说中，最令人恐惧的恶灵之一是“飞头蛮”（Penanggal / Penanggalan）。它通常被描述为在夜间飞行、只剩下一颗女性头颅以及挂在脖子下滴血的内脏（胃、肠）的怪物。它被认为会吸食孕妇或婴儿的血液。水手们在夜航靠近红树林时对其极度恐惧。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 东南亚海域夜航时极低概率触发的恐怖事件，导致船员患病或士气暴跌（可用特定草药驱散）。
* **Q2 异**：✓ 极具东南亚本土视觉冲击力（头颅+内脏飞行）的恐怖传说，完全不同于欧洲的“海妖”（Siren）。
* **Q3 链**：✓ 链接东南亚沿岸航行危险、迷信事件机制、医疗系统。
* **分级**：必加（L4 本土神秘学与异化生物）。

## 3. 视角自查 (P1-P5)
* **马来水手视角**：千万别在晚上靠近那片红树林！我发誓我看到了一团挂着肠子的发光脑袋从树冠上飞过去！
* **信标会视角**：对夜行性发光生物或寄生虫感染的极度恐惧投射。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Ali (克服家乡的古老恐惧) / Ernst (从医学角度解构民间鬼话)
* `darkLineLayer`: L4（夜行生物与寄生虫病的神话化）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“晚上睡觉把船舱的缝隙都给我堵死！如果你在马六甲的红树林边闻到一股浓烈的血腥味，那就是‘Penanggal’来了！那是一颗挂着滴血肠子在天上飞的女人头，专门吸活人的血！”
* **记录 (Archives Record)**：“马来文化中最著名的灵异传说之一（Penanggalan）。相传由修炼黑巫术走火入魔的女性变成。其夜间游荡、头颅与内脏与身体分离的诡异形象，构成了前殖民时代东南亚沿海渔民和水手最深层的集体梦魇。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】飞头蛮（Penanggal）的恐怖，是黑夜、瘴疠与无知合谋的产物，与巫术无关，也与海底的任何东西无关。本会在马六甲海峡的红树林深处见过这一带特有的大型夜行吸血蝠蛾：它腹下有半透明的储血囊，受惊或求偶时透出微弱的生物荧光——这本是红树林湿热环境里寻常的发光现象。试想一名水手深夜泊船红树林边，舱中已有人染上产褥热或疟疾、缠绵血污，恰逢一只拖着荧光血囊的飞蛾扑面掠过：恐惧会替他把零碎的影像拼成一颗挂着肠子、滴着血飞行的女人头。把孕妇与婴儿的失血之厄归咎于一个会飞的恶灵，是前殖民时代沿海渔民对难产、寄生虫病这些无从理解的死亡，所能找到的一种解释。本会记录它，不为追查什么泄露或防线，只为留住这条提醒：传说里最骇人的怪物，往往是人对疾病与黑暗的恐惧，借一只寻常生灵显了形。”
