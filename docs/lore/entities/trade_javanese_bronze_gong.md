# 实体档案：爪哇青铜锣 (Javanese Bronze Gongs)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：菲律宾 Lena Shoal 沉船（1490年代）及 Brunei 沉船（1500年代）的考古发掘物资清单。
* **L2（学术）**：在这些满载大明瓷器的沉船中，考古学家同样发现了大量非瓷器类的高价值本土贸易品，其中最显著的就是“青铜锣”（Bronze Gongs）。在东南亚，铜锣不仅是乐器（如加美兰 Gamelan 的核心），更是彰显土王身份、进行部落交易的硬通货和礼器。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 东南亚/爪哇海域的高端本土贸易品，特定土著港口极度渴求。
* **Q2 异**：✓ 突破了“大航海只有香料和瓷器”的局限，展现了东南亚内部繁荣的金属礼器贸易网。
* **Q3 链**：✓ 链接东南亚内海航线、土著苏丹国、Ali 的商贸垄断线。
* **分级**：必加（L2 区域商业网）。

## 3. 视角自查 (P1-P5)
* **东南亚视角**：青铜锣的声音是连接祖先与神明的桥梁，拥有越多的古锣，部落的权力与威望就越高。
* **大明/西方视角**：这些土著居然愿意用成箱的胡椒来换这些笨重的铜盘子，这简直是暴利。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Ali (掌控东南亚内部贸易命脉) / Ernst (记录本土音乐与礼器)
* `darkLineLayer`: L2（区域硬通货的商业炒作）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“满载大明瓷器去满者伯夷？你这外乡人真是不懂行情。在那群岛礁里，土王们更看重那些沉甸甸的爪哇青铜锣！一面敲得响的好锣，能换来一整座岛的香料采摘权！”
* **记录 (Archives Record)**：“大航海时代早期东南亚海域的关键本土贸易品。沉船考古证明，除了瓷器，商船底舱常装载大量的锡锭、铜线与青铜锣。这些金属器具在婆罗洲和菲律宾的部落中被视作财富与权力的终极象征。”
* **博物 (Exhibit Description)**：“【信标会内参：温和派誊本】大明商贩笑话土王肯用成箱胡椒去换笨重的铜盘子，是只算了金属的斤两，没算它在群岛里的分量。在婆罗洲与菲律宾的部落中，青铜锣从来不是寻常乐器：一面音色醇厚的好锣，是土王身份的凭证、部落间议婚定盟的礼器、可代币流通的硬通货，铸锣的工艺与好锣的来历更被层层神圣化。它那浑厚悠长、能传出极远的低频锣声，在加美兰（Gamelan）合奏里被视作沟通祖先与神明的桥梁——人在那震彻胸腔的余韵里生出敬畏，本是声音之于人心最自然的感染，与海底是否有什么在共鸣毫不相干。本会记录它，与失落王国的遗产无涉，只为留住东南亚内部一张被‘大航海只有香料与瓷器’的成见所遮蔽的繁荣金属礼器贸易网：在欧洲人到来之前，这片群岛早有自己的财富、自己的硬通货、自己的神圣之声。”
