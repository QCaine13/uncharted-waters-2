# 实体档案：阿达马斯托的狂怒 (Wrath of Adamastor)

## 1. 采集 (L1/L2 史实锚点)
* **L1（权威）**：葡萄牙诗人路易斯·德·卡蒙斯 (Luís de Camões) 的史诗《卢济塔尼亚人之歌》(Os Lusíadas) [4, 5]。1554年葡萄牙大帆船 São Bento 号在南非海岸的惨烈沉没记录 [6, 7]。
* **L2（学术）**：“阿达马斯托”被具象化为好望角（风暴角）的敌对神话巨人，代表了自然界对葡萄牙人试图突破印度洋的终极惩罚 [4]。

## 2. 筛选 (准入三问)
* **Q1 玩**：✓ 航经好望角时的极端天气/灾难事件，可能导致舰队严重受损。
* **Q2 异**：✓ 结合了真实极端气候与欧洲航海恐惧的具象化实体。
* **Q3 链**：✓ 链接葡萄牙皇家舰队的扩张、Joao 的主线生存考验、Catalina 的海战场景。
* **分级**：必加（L4 神秘学暗线）。

## 3. 视角自查 (P1-P5)
* **欧洲视角**：挑战上帝与自然极限的恐怖试炼，战胜它意味着帝国霸权的建立。
* **非洲/本地视角**：这是保护印度洋免受西方战火侵扰的天然屏障，是非洲海岸拒绝入侵者的愤怒化身。

## 4. 钩子设计 (storyHooks)
* `protagonist`: Joao (突破好望角的生死考验) / Catalina (借助风暴伏击仇人)
* `darkLineLayer`: L4（神秘学与地理屏障）

## 5. 三层文本 (Text Layers)
* **风闻 (Pub Gossip)**：“别在起风的时候靠近好望角！我发誓，我在黑云里看到了一张巨大的、由岩石和闪电组成的人脸。它要把所有悬挂葡萄牙十字旗的船都拖进海底！”
* **记录 (Archives Record)**：“自达伽马以来，无数满载香料的巨舰（如 São Bento 号）在好望角粉身碎骨 [7]。文人们将这片海域的极端洋流和风暴拟人化，称其为巨人‘阿达马斯托’（Adamastor）的诅咒 [4]。”
* **博物 (Exhibit Description)**：“【信标会内参：极端派行动日志】好望角的磁场异常和恶劣气象是天然的防线。我们在里斯本的酒馆里刻意散播、放大了‘阿达马斯托’的恐怖神话，以此来恐吓那些贪婪的冒险家。只要能阻止他们大规模进入印度洋发现‘普世遗产’，沉几艘帆船的代价是值得的。”

> **博物层分类：[留-原始信标会]** — 信标会散播神话以阻止他人发现普世遗产；磁场异常为自然现象，未涉及远古机器。
