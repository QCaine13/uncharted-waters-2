### D9 — 项目定位收敛为「一个真能玩的游戏」，切片按可玩性排序
- 日期：2026-08-13 · 来源：用户重新定向（「先不按照文档来，我们重新订一下方向」）
- 定位：验收标准是**陌生人能坐下来玩两小时不腻**，而非叙事作品 / 代码作品集 / 完整复刻。
- 切片顺序：**B 价格波动 → A 断粮惩罚 → C 探索发现 + 激活 fame → D 决斗/海战**。
  B 排第一是因为价格恒定不是「少了点变化」而是**经济系统失效**：利润线性且无上限，
  金钱在约二十分钟内失去意义，同时抽空船厂 / 雇佣 / 补给 / 投资的决策content。
  C 是双份收益——既是第二个玩法循环，也是 João 中段（圣者之杖 / 马萨瓦）与 Pietro 整条线的硬前置。
- 剧情范围收敛：**先补完 João 一条线，不是 6 条**。原作节拍可考（`1-baseline/story-outline.md`），
  但**对白必须原创**（守既有纪律 + 版权）。6 条路线里 5 条依赖尚不存在的系统。

### D10 — 市场采用单一参考价 + 固定价差 + 相场指数
- 日期：2026-08-13 · 来源：`docs/superpowers/specs/2026-08-13-market-price-dynamics-design.md`
- 起因：原 Market MVP 的买价 / 卖价是两个**互相独立**的函数，凡在 `demands` 而不在 `supplies`
  的商品即 `卖价 > 买价`，**同港套利**，全 13 市场共 55 对（里斯本 Pepper 150 进 270 出）。
- 决策：买卖价统一由**单一参考价**（基准价 × 区域倍率 × 相场/100）加 **±10% 价差**导出，
  使 `买价 > 卖价` 成为**结构性不变量**而非数值巧合；回归测试扫满 13×24×161 全组合。
- 相场指数每（市场×商品）一个，`[40,200]`，买推高卖压低；交易**按块结算**，
  故倾销边际收益递减。回归到 100 用**惰性计算**（存 `updatedDay`，读时推导），
  刻意不挂日 tick——纯函数、无世界循环耦合、跨存档与长时间间隔均正确。
- 存档升到 v3（沿用 D6 的迁移链），仅新增 `marketPrices`；`quests` / `fame` 不动，
  故 D8 的 Save v2 剧情兼容边界不受影响。
