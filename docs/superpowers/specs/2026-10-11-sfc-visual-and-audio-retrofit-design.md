# 方案设计：SFC（超任）复古画风与音频质感重塑 (Visual & Audio Retrofit)

- **设计日期**：2026-10-11
- **适用分支**：`master`
- **关联决策**：[D20](../../DECISIONS.md#d20--sfc-画风与音频质感重塑)
- **前置基线**：M0（中文基础）、M1（首次航海）、M2（冲突与成长）、M3（约翰归家终章已全部合入 `master`，存档格式为 `v7`）

---

## 1. 背景与改造目标

### 1.1 现状与痛点
当前项目的核心游戏机制、数值模型和 M0–M3 约翰·法雷尔完整剧情已经非常扎实（102 套测试全部通过），但目前的表现层存在以下核心痛点：
1. **美术资源受限于 MD 8 色限制**：目前使用的立绘源自世嘉 Mega Drive (MD) 提取资源（如 `src/interface/images/characters.png`），单角色仅使用 8 色高对比度色块，阴影生硬，缺少过渡微调。
2. **UI 偏向现代扁平管理台风格**：对话框与侧边栏采用 Tailwind 现代无衬线卡片设计，与中间的复古像素画布存在一定的视觉断层。
3. **缺少 SFC 标志性的音画灵魂**：缺少 SFC 版经典的羊皮纸木纹质感、CRT 扫描线氛围选项，以及对话时的像素打字机音效。

### 1.2 升级目标
在**绝不破坏现有游戏逻辑、存档（v7）兼容性、E2E 测试与自动化交付基线**的前提下，将视听体验整体跃升至 **SFC（超任）原版巅峰质感**：
* **立绘与肖像**：将 8 色立绘全面升级为 SFC 纯正 16 色（4bpp）水彩油画质感立绘。
* **界面与对话框**：重构对话框为经典 SFC 羊皮纸底板 + 雕花木框 + 闪烁三角指引符。
* **复古音效引擎**：通过 Web Audio API 引入 SFC 经典的程序化合成打字音（按角色定制音调）与确认音。
* **显示增强**：在「系统」设置中提供“CRT 扫描线 / 复古像素”平滑滤镜切换。

## 2. 详细技术方案

### 2.1 资产管线升级：SFC 16 色立绘表替换
* **目标文件**：`src/interface/images/characters.png`（以及引用它的 UI 渲染层）。
* **技术标准**：
  * 保持单角色切割尺寸 `64×80` 像素不变，保持索引布局与角色 ID 对应关系（`characterId * 80` 偏移）。
  * 色彩深度从 8 色扩展至完整的 16 色调色板（支持半透明或 1 色透明），提取自 SFC 原版 ROM，还原本作画师小林智美的高级灰、象牙肤色与深绀蓝高光。
  * 优先更新主线出场核心角色：约翰·法雷尔、莱昂·法雷尔公爵、洛克·阿兰克尔、多明戈、卡特琳娜、路琪亚、阿兰、奥托等。

### 2.2 对话框组件的 SFC 复古化改造
* **目标文件**：`src/interface/dialog/` 相关组件。
* **UI 规格**：
  * **背景**：采用 SFC 羊皮纸色（`#eddcc0`），内衬带细腻微噪点或横向微纹理。
  * **边框**：外层深深棕色木纹（`#2c1a0e`），内层 1px 古典金边线条（`#d4a742`）。
  * **文字与排版**：采用复古深棕黑字体（`#22140a`），行高 1.6，标点与字距更具节奏感。
  * **翻页指示符**：在对话末尾加入 SFC 原版的黄色/朱红倒三角动画（`▼`），逐字打完后呼吸闪烁。

### 2.3 零依赖 Web Audio 复古音效合成
* **目标实现**：`src/sound/sfcAudio.ts`（单例模块）。
* **设计原则**：不引入几兆的外部 mp3 文件，利用 Web Audio API 实时生成低功耗合成波：
  * **打字嘟嘟声**：采用柔和的三角波（Triangle Wave），时长 40ms，衰减斜率 0.001。
    * 莱昂公爵：420Hz（威严沉稳）
    * 洛克大叔：360Hz（豪迈粗犷）
    * 约翰·法雷尔：580Hz（青年英气）
    * 旁白/系统：640Hz（清脆轻盈）
  * **选项确认与按键音**：双频正弦扫频音（440Hz -> 880Hz）。
  * 在「系统」菜单中增加独立音效开关（持久化至 `localStorage`），尊重静音偏好。

### 2.4 可选的 CRT 模拟与视口优化
* **实现机制**：通过 CSS 类 `.sfc-crt-scanlines` 叠加轻量级无性能损耗的渐变背景。
* **开关位置**：放置在左侧「系统」菜单内，与现有的「中英切换」并列，即开即关，完全不影响核心画布渲染逻辑。

## 3. 兼容性与质量保障（Non-breaking Guarantees）

1. **存档格式兼容（v7 原样保持）**：本轮纯为视觉与音频层升级，不增删任何持久化 state 字段，现有通关存档完全无缝加载。
2. **既有测试全量通过**：
   * 必须确保 `npm run verify`（包含 102 套单元测试、TS 检查、ESLint、生产打包）100% 退出码 0。
   * 确保角色 ID 与坐标系不漂移，Cypress E2E 航行与对话点击选择器保持一致。
3. **自动化交付授权执行（D19 遵守）**：
   * 完成方案验证后，将改动规范提交，合并到 `master` 并安全推送至 `origin/master`。
