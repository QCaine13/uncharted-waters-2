## 约翰路线的实施核对点

先按中文全主线资料建立事件链，再对照实际游戏画面验证各阶段入口和出口。资料中有：多明戈身份事件、卡特琳娜追击及阿兰寻亲委托、马沙华与圣者之杖、恩里克赴日、南美决战及回乡。冒险名声是推进门槛之一，但仅有足够名声不等于已满足全部前置事件。

实测攻略标出的关键名声为 2000 / 8000 / 16000 / 30000 / 40000，分别对应上述五段。它们是原版核对基准，不直接决定重制版节奏；若为可玩性改变门槛，必须记录为设计调整，不能冒称原版规则。部分单挑/海战允许失败或撤退推进，最终战需要胜利，因此实现不能把所有遭遇一律设为必胜。

## 中文化规则

1. 保留稳定 ID 与英文菜单 action value，中文只负责显示。
2. 玩家自定义船名是存档数据，语言切换不得改写。
3. 人物、城市、船型、商品、装备与系统提示分别维护；同一词在“商品名称”和“资金数量”语境可能不同。
4. 新对白原创，现有对白汉化保留原意、人物关系和提示线索，特别是时间/金额/条件。
5. 标明资料版本；不把《起源》《Online》或外传内容混入二代基线。
6. 每个交付阶段检查可见中文、动态参数、确认按钮、换行、存档恢复和英文回退。

## 待核对项

- 原中文版中非主角人名、船型与少数港名的具体用字，以游戏画面补充验证。
- 不同平台的剧情地点、数值和战败处理差异，按将要实现的章节逐项查证。
- 资料表中的商品/宝物编号与当前项目 ID 映射，禁止凭相同数字合并。
