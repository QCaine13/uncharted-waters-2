# 晨星港 · 整幅场景铺开（共 11 张）

试点图 `scene/output/district-quay-market.png` 已通过，画风、细节密度、光线、色调都以它为唯一标准。
现在按同样的画法把整座晨星港画完。本项目是原创的架空航海题材 2D RPG，所有设计均为原创。

## 分区

整张地图 96×96 格、每格 32 像素。分成 11 个街区，每张 1536×1024（48×32 格），相邻街区有重叠。
分区定义见 `art/chatgpt/scene/districts.json`，**按其中 `order` 的顺序做**：

C2 → C1 → C3 → B2 → B1 → B3 → A2 → A1 → A3 → D1 → D2

## 每一张的做法

1. 先运行 `python3 art/chatgpt/scene/make_base.py <编号>`，生成底图 `art/chatgpt/scene/base/<编号>.png`。
   这个脚本会把**已完成的相邻街区**贴进底图的重叠区域，所以必须做完一张再生成下一张的底图。
2. 用 ImageGen 以这张底图为参考做图生图，直接出一整张成品。脚本只允许用于生成底图、缩放和保存，
   **不要用脚本拼贴或绘制成品**；调不了就停下说明。
3. 保存为 `art/chatgpt/scene/output/<编号>.png`，1536×1024，与底图同构图、可逐像素叠放。

## 硬性要求（和试点相同）

- 每栋建筑的位置、占地轮廓、门的位置，道路走向和宽度，石板码头范围、岸线、城墙位置，偏差不超过半格（16 像素）。
- 底图里**已经是成品画风的区域**（贴进来的相邻街区）要原样延续：同一条路、同一片草地、同一段城墙、
  同一片水面在接缝两侧的颜色、纹理、亮度必须连续，不要重新设计。
- 视角：正面俯视（屋顶在上、正立面在下）。
- 不画任何人物或动物（底图里的小人不要保留）。
- 道路和门前留空，装饰物只放在不挡路的地方。
- 光线统一：左上方的暖色午后日光，和试点一致。
- 建筑的门、招牌、屋顶颜色与底图里的保持一致（只提升细节，不换设计）。

## 各区补充

- **C2**：就是试点那一区，只是整体上移了两格，底图里已贴入试点成品。保持试点的全部内容，
  只需补画顶部新露出的两行，并把三艘帆船整体上移约 50 像素。帆船和小船的船体不要进入画面最下方 3 行（96 像素），那里只留开阔水面。
- **C1 / C3**：帆船、小船同样不要进入最下方 3 行。C1 是教堂和西侧沙滩，C3 是造船厂、东码头和沙地。
- **B 区**：城区内部。草地要有花丛、菜畦、矮墙、围栏、水井、晾衣绳、长椅、路灯等生活细节；
  池塘画成有睡莲和石岸的观赏池。
- **A 区**：王宫和城墙。城墙要有垛口、藤蔓、风化痕迹、旗帜，不要一面重复的砖；
  王宫前的草地做成修剪整齐的花园。三张之间的城墙和王宫立面要连续一致。
- **D1 / D2**：只有开阔海面，延续上方街区的水色和波光。上半张会被其他街区盖住，
  下半张可以有一两处礁石或远处的小帆影，不要大船。
