# 晨星港 · 两处局部修正

11 张街区已通过，整体画风不变。现在只修两处，各出一张 1536×1024 的修正图。
本项目是原创的架空航海题材 2D RPG，所有设计均为原创。

每处有两张输入图（都在 `art/chatgpt/scene/patch/`）：
- `P?-base.png`：当前成品画面，作为图生图底图。
- `P?-guide.png`：同一张图加了标记，只用来说明位置。**成品里不要出现任何标记线。**

用 ImageGen 以 base 为底图做图生图，直接出成品；不要用脚本拼贴或绘制。
除了下面说明要改的地方，画面其余部分（其他建筑、道路、草地、花丛、杂物、光线、色调）
要尽量和 base 保持一致，位置不动。不画人物和动物。

## P1：大宅正门与门前灌木

- 大宅一层的正门现在画在青色方框的右边。请把**正门移到青色方框的位置**
  （门洞正好占满青色方框，64×64 像素），门的样式不变；
  原来门的位置改成和两侧一样的墙面与窗；青色方框处原有的花盆和壁灯挪到新门的两侧。
  从门口通向下方大路的小路也相应左移，正对新门。
- 洋红色圆圈的位置各画一株**修剪成球形的小灌木**（约 32×32 像素一株，带投影），
  排成一排整齐的树篱，清楚醒目。圆圈以外的这一排不要放灌木。
- 输出 `art/chatgpt/scene/output/P1.png`。

## P2：公会正门

- 画面上方那栋红瓦建筑（带三个拱形橱窗）的门现在画在青色方框的右边。
  请把**门移到青色方框的位置**（门洞占满青色方框，64×64 像素），样式不变；
  原来门的位置改成墙面；门旁的招牌、花盆、壁灯跟着移到新门两侧。
  三个拱形橱窗可以相应向左收窄，但建筑外轮廓不变。
- 输出 `art/chatgpt/scene/output/P2.png`。
